# Employee Management System

A simple Spring Boot application to manage employee records with CRUD operations and search functionality.

## Features
- Add, update, delete employee
- View all employees
- Search employee by name
- REST API endpoints
- MySQL database integration

## Technologies
- Java 17, Spring Boot
- MySQL
- Maven
- HTML/CSS (basic frontend)

## How to Run
1. Clone the repo:
```bash
git clone https://github.com/kanchan409/Student_Management_System.git
cd Employee_Management_System
Configure MySQL in application.properties

Run the project:

mvn spring-boot:run
Test APIs at http://localhost:8083/api
